# Aim Threshold Tracker

[![Download](https://img.shields.io/github/v/release/Arthur-galvao/aim-threshold-tracker-app?label=download&style=for-the-badge)](https://github.com/Arthur-galvao/aim-threshold-tracker-app/releases/latest)

App desktop pra rastrear seus thresholds de mira no KovaaK's, seguindo a metodologia do benchmark Viscose e do padrão Escalate.

## Download

**[⬇️ Baixar instalador (.exe)](https://github.com/Arthur-galvao/aim-threshold-tracker-app/releases/latest)**

Windows apenas. Não precisa de admin pra instalar.

## Como funciona

O app detecta automaticamente a pasta de stats do KovaaK's (via Steam) e observa em tempo real quando você termina uma run. Cada CSV novo é lido, a pontuação é registrada no histórico da task correspondente, e você acompanha PB, threshold e evolução direto no app.

Se a detecção automática não achar sua pasta, dá pra selecionar manualmente pelas configurações do app.

Seus dados ficam salvos localmente na sua máquina — nada é enviado pra nenhum servidor.
